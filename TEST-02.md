## Task 1 — Student Marks System — 10 Marks

Create a program that asks the user to enter:

* Student name
* Age
* Marks in Python
* Marks in Linux
* Marks in AWS

Store all values in appropriate variables.

Then:

1. Convert `age` and marks to appropriate numeric data types.
2. Calculate the **total marks**.
3. Calculate the **average marks**.
4. Check whether the average is greater than or equal to `40`.
5. Display the student's name, age, total, average.
6. Display the data type of the age and average.

Example:

```text
Enter student name: Aman
Enter age: 21
Enter Python marks: 85
Enter Linux marks: 72
Enter AWS marks: 65

Name: Aman
Age: 21
Total Marks: 222
Average: 74.0
Age Type: <class 'int'>
Average Type: <class 'float'>
```

**Total Marks: 50**
**Questions: 5**
**Difficulty: Beginner → Intermediate**

## Question 1 — Set Operations (10 Marks)

Create two sets:

```python
students_python = {"Aman", "Simran", "Ravi", "Neha", "Karan"}
students_java = {"Ravi", "Neha", "Pooja", "Karan", "Raj"}
```

Perform the following operations:

1. Find students who are enrolled in **both Python and Java**.
2. Find students who are enrolled in **Python but not Java**.
3. Find students who are enrolled in **at least one course**.
4. Find students who are enrolled in **both courses**.
5. Find the total number of unique students.

**Marks: 2 marks each**

## Question 2 — Set Methods (10 Marks)

Create a set:

```python
fruits = {"apple", "banana", "mango", "orange"}
```

Perform the following:

1. Add `"grapes"` to the set.
2. Add multiple fruits: `"kiwi"` and `"papaya"`.
3. Remove `"banana"`.
4. Check whether `"mango"` exists in the set.
5. Find the length of the set.

Use appropriate **set methods** wherever possible.

## Question 3 — Student Dictionary (10 Marks)

Create the following dictionary:

```python
student = {
    "name": "Navjot",
    "age": 30,
    "course": "Python",
    "marks": 85
}
```

Write a Python program to:

1. Print the student's name.
2. Print the student's course.
3. Update the marks to `90`.
4. Add a new key `"city"` with value `"Ludhiana"`.
5. Print all keys and values using a loop.

## Question 5 — Practical Set + Dictionary Problem (10 Marks)

A training institute has two Python batches.

```python
batch1 = {"Aman", "Ravi", "Neha", "Simran", "Karan"}
batch2 = {"Neha", "Karan", "Pooja", "Raj", "Simran"}
```

Create a dictionary containing the marks of some students:

```python
marks = {
    "Aman": 75,
    "Ravi": 82,
    "Neha": 90,
    "Simran": 88,
    "Karan": 65,
    "Pooja": 79,
    "Raj": 72
}
```

Write a program to:

1. Find students present in **both batches**.
2. Find students present **only in Batch 1**.
3. Find students present **only in Batch 2**.
4. Find the marks of students who are present in **both batches**.
5. Find the **highest-scoring student among the students present in both batches**.
